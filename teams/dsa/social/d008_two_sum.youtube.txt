Two Sum Explained: Brute Force to Hash Map

Two Sum: given an array and a target, return the indices of the two numbers whose sum is the target; each element can be used once. Brute force checks every pair (10 pairs for 5 numbers; about 50 million for 10,000 numbers, an example). With a hash map, for each number compute its complement (target minus the number), check whether it was seen before, and store the number with its index only after that check. Dictionary lookup is average O(1), so time is O(n) on average and extra space is O(n); a lookup can be O(n) in the worst case, so O(n) worst-case time is not guaranteed.
