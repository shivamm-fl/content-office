Day 17/150: Longest Consecutive Sequence: sort ke bina O(n) mein!

Longest Consecutive Sequence mein unsorted array ka sabse lamba consecutive run dhoondhna hai. Sort karke scan chalta hai, par sorting O(n log n) hai, aur interviewer O(n) maangta hai. Sort sirf isliye thi ki x ke baad x+1 paas mein mile; hash set yeh average O(1) mein kar deta hai. Par har number se walk shuru karo to [1..2000] jaise array par lagbhag 2 million lookups lagte hain (example).

Fix: walk sirf run ke start se shuru karo, yaani us x se jiska x-1 set mein nahi hai. Example [100, 4, 200, 1, 3, 2]: starts 1, 100, 200; 1 se run 1, 2, 3, 4 banta hai, answer 4. Har run ka ek hi start hota hai, to har number zyada se zyada ek baar walk hota hai, baaki par ek check: lagbhag 4 thousand lookups. Time O(n), extra space O(n); duplicates set mein ek baar aate hain. Actual Python code video mein hai, example par chalaya hai.
