Set Matrix Zeroes In Place: O(1) Space Markers

Set Matrix Zeroes (LeetCode 73) asks you to set the whole row and column of every zero cell to 0, in place. Zeroing while scanning cascades: new zeros look like original zeros and the example [[0,1,2,0],[3,4,5,2],[1,3,1,5]] ends up all zeros (the code was run to check this). Recording the zero rows and columns in two extra arrays takes O(m + n) space. The in-place method uses the first row and first column as markers, plus two booleans that remember whether the first row and the first column originally had a zero. It runs in O(m x n) time and O(1) extra space and gives [[0,0,0,0],[0,4,5,0],[0,3,1,0]] on the example.
