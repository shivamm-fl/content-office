Longest Consecutive Sequence in O(n): Start of Each Run

Longest Consecutive Sequence asks for the length of the longest run of consecutive integers in an unsorted array. Sorting and scanning works but costs O(n log n). Put all numbers in a hash set (average O(1) lookup) and begin counting only at numbers x whose x - 1 is not in the set, the start of a run. Example: nums = [100, 4, 200, 1, 3, 2] has starts 1, 100 and 200, and the run from 1 is 1, 2, 3, 4, so the answer is 4 (the code shown was run; [0,3,7,2,5,8,4,6,0,1] gives 9). Each run has one start, so each number is walked at most once: O(n) time and O(n) extra space (our own analysis). Example arithmetic: on [1..2000], walking from every number needs about 2 million lookups, versus about 4,000 with the start check.
