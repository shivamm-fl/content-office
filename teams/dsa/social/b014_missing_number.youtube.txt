Missing Number | Blind 75 14/75

Given array: [4, 0, 2, 1]. Missing value: 3.

Full range 0..n aur present values XOR karo. Equal copies cancel hongi, missing value bachegi. One pass, O(n) time aur O(1) extra space; input mutate nahi hota. Distinct values ki guarantee zaroori hai.
