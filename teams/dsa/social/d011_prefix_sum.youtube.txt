Prefix Sum: Range Sum Queries in O(1)

A prefix sum is the sequence of running totals of an array. Build it once in O(n) with a leading 0, so prefix[i] is the sum of the first i elements. Then the sum of indices left..right is prefix[right + 1] - prefix[left]: two reads and one subtraction, O(1) per query, with O(n) extra space. Example: for [3, 1, 4, 1, 5, 9] the prefix array is [0, 3, 4, 8, 9, 14, 23] and the sum of indices 2..4 is 14 - 4 = 10, the same as 4 + 1 + 5 (checked by running the code against a brute-force loop for every range). Example arithmetic: with 100,000 numbers and 100,000 queries, a worst-case loop does 10,000,000,000 additions, while the prefix array does 100,000 additions to build plus 100,000 subtractions. The trick needs an operation you can undo, so it works for sum but not for max.
