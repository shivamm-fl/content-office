What is DSA? Data Structures and Algorithms explained in Hinglish

DSA is two things: a data structure (how data is kept) and an algorithm (the steps that use it). Example run in Python on 1,000,000 sorted numbers, target last: one by one 1000000 comparisons, binary search 20 (counts, not seconds). Binary search needs a sorted list.
