Contains Duplicate and Valid Anagram: One Hash Map Idea

Contains Duplicate: return true if any value appears twice. Instead of sorting or comparing every pair (8 pair checks on a small example list; about 50 million for 10,000 numbers, an example), keep a set of values already seen: if the current value is in the set, return True, otherwise add it. Time is O(n) and extra space O(n), against O(n log n) for sorting; a hash lookup can be O(n) in the worst case, so this is the average case. Valid Anagram: instead of a set, keep a count of each character in a hash map (Python's Counter); two strings are anagrams when the counts match. Counting is O(n) time and O(26) space for lowercase letters.
