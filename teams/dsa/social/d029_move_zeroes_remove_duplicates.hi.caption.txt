Day 29/150: Move Zeroes aur Remove Duplicates, bina naya array banaye, ek hi pattern se

Move Zeroes: saare zeros aakhir mein, baaki numbers ka order wahi. Brute force har zero par baaki numbers ek jagah left khiskata hai: 10,000 numbers mein pehle 5,000 zeros hon to lagbhag 50 million shifts, yaani O(n^2).

Trick: har non-zero ka naya index = usse pehle aaye non-zero ki ginti. Wahi ginti write pointer hai. Read pointer har number ek baar padhta hai; non-zero mila to write wali jagah se swap karo aur write aage. [0, 1, 0, 3, 12] ban jaata hai [1, 3, 12, 0, 0].

Remove Duplicates (sorted array): ek jaise numbers saath baithe hain, to number naya tabhi hai jab aakhiri rakhe number se alag ho. Write 1 se shuru, naya number mila to write par likho, write aage. [0,0,1,1,1,2,2,3,3,4] par answer 5.

Dono mein time O(n), extra space O(1). Python code video mein hai (random arrays par brute force se match kiya).
