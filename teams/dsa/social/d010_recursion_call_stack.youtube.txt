Recursion and the Call Stack: Base Case and RecursionError

A recursive function calls itself on a smaller input until a base case returns a value directly, without a further recursive call. Each active call keeps one frame on the call stack (typically its arguments and local variables); a frame is pushed on a call and popped on a return. For factorial, fact(5) makes 6 calls with a maximum depth of 6, and returns 120 (run on CPython 3.12). Without a base case the calls never stop and Python raises RecursionError: maximum recursion depth exceeded. Even with a correct base case there is a limit: CPython's default is about 1000, so total(10000) written recursively fails with the same error, while a loop gives 50005000 with a single frame.
