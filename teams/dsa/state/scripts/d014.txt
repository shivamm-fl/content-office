Maximum Subarray problem में largest contiguous sum कैसे निकालोगे? | Given array: minus two, one, minus three, four, minus one, two, one, minus five, four।

Contiguous मतलब बीच के elements skip नहीं कर सकते। | यहाँ four, minus one, two, one का sum six है। | हमें non-empty subarray का maximum sum लौटाना है, सारे positive elements अलग अलग चुनना valid नहीं।

सीधा तरीका हर start से आगे चलकर running sum निकालना है। | Nine elements में forty five subarrays हैं। | General case में n times bracket n plus one, divided by two; यानी O n squared time।

अब current element four पर आओ। | उससे ठीक पहले तक best ending sum minus two था। | उसे extend करो तो minus two plus four, यानी two। Four से नया subarray शुरू करो तो four। | Negative पुराना sum साथ लेने से answer घट रहा है।

इसलिए हर index पर दो choices compare करो: current value से restart, या पिछला ending sum extend। | इनके maximum को current कहेंगे: best sum जो इसी index पर खत्म होता है। | Best नाम का दूसरा variable अब तक का सबसे बड़ा current रखेगा।

Four पर current four, best four। | Minus one जोड़कर current three, best अभी four। | Two जोड़कर current five और best five। | One जोड़कर दोनों six।

अब minus five पर current one हो जाएगा, लेकिन best six रहेगा। | Last four जोड़कर current five होगा; best फिर भी six। | इसलिए final current लौटाना गलत होगा; maximum कहीं पहले खत्म हो सकता है।

यही actual Python solution है। | Current और best को first element से initialize करो। | Loop में restart और extend compare होते हैं, फिर best update होता है। | मैंने इसी code को examples और five thousand random arrays पर brute force से compare किया है।

Given array: minus five, minus two, minus eight। | Answer minus two है। | Best को zero से initialize करोगे तो zero निकल सकता है, लेकिन empty subarray allowed नहीं है। First element से शुरुआत यह bug रोकती है।
