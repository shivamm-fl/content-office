# Roadmap

`series-150.json` is the plan of 150 Days of DSA: 14 phases, one entry per day with its `format` (concept, structure, pattern, problem, recap), `level` for problems, `status` (todo, in_progress, done) and `reels` (the ids built for it).

Day N is item `d` + N in three digits. The strategist plans the next `todo` days in order (`prompts/plan-series.md`). The file is the owner's plan: agents propose changes, they do not make them.

Titles are public names of classic problems and ideas, used as a checklist only. Nothing from any problem page, editorial or other channel's list is copied; scripts, code and examples are written fresh from fetched sources.
