# Visual plan: s002 Client, server aur API

Idea in one line: a client asks (request), a server answers (response), an API is the menu of what you may ask.
The picture that explains it with the sound off: a phone and a computer rack with a REQUEST card going one way and a RESPONSE card coming back; a restaurant (customer, waiter, kitchen) drawn beside the same three roles; the menu card with Mars crossed out; a server box whose tag flips to CLIENT.
