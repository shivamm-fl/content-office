# Visual plan: s026, one server to a fleet (6 stops)

Idea in one line: a request walks down one fixed vertical route; each stop is a box that appeared because one thing filled first, and any box that stays single is the next single point of failure.
The picture: one fixed route frame (user on top, then CDN, API gateway, load balancer, app servers, cache, database with replicas), built stop by stop; a red meter beside a stop empties as its box appears; the end is one static table of all 6 stops with their "what filled" answer.
