# Visual plan: s001, Day 1, System design kya hai (concept, interviewer_asked)

Idea in one line: system design = choose the parts of a system and how they connect to meet requirements at a scale; answer in a commonly taught order (requirements and scale, design, detail, trade-offs).
The picture that explains it with the sound off: one whiteboard-like story. A question mark, ONE running example (a food-delivery app, EXAMPLE) built in four steps: a requirements checklist and a users-to-requests division, parts joined by arrows, a database table, a balance scale FRESH vs FAST.
