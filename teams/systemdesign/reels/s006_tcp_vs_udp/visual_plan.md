# Visual plan: s006 TCP vs UDP

Idea in one line: when a packet is lost, TCP resends it and waits so everything arrives complete and in order; UDP moves on. The deciding question is whether a late old piece is still worth anything.
The picture that explains it with the sound off: a sender and a receiver with numbered packet squares travelling between them (vertical layout). TCP shows a handshake, numbered packets and a resend of the lost one until the row is complete; UDP shows packets streaming with one dropping off while the rest keep moving; a voice waveform shows UDP with a tiny gap and TCP stuck waiting.
