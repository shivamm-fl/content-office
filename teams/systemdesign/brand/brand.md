# Brand (Learnvora family, theme v1)

Learnvora System Design is one of three Learnvora floors: ai.learnvora (gold), dsa.learnvora (violet), systemdesign.learnvora (cyan). Same navy base, same type, same layout; only the accent changes, so the three grids read as one company and each handle still has its own colour.

| Token | Value | Use |
|---|---|---|
| bg | #0B1220 | background (deep navy) |
| panel | #131C2E | cards, code panels |
| text | #F3EFE6 | main text (warm ivory) |
| muted | #8FA0B8 | secondary text, labels |
| accent | #4CC9F0 | THE accent of @systemdesign.learnvora: highlights, active word, day counter, pill |
| good | #6FD3A6 | right / passing only |
| bad | #E5735F | wrong / failing only |
| blue | 108,140,213 | data and vectors |

Contrast on bg: text 16.3, muted 7.0, accent #4CC9F0 at or above 6.8 (checked 2026-10-18). Text on an accent fill is navy.
Fonts (local `brand/fonts/`, OFL): Space Grotesk (headlines), JetBrains Mono (code, labels, the day counter), Noto Sans Devanagari.
Mark ("The Bite", owner-approved 2026-10-18; files in `company/brand/learnvora-logo/`): a disc with a V bitten out of the top, in the handle's accent (cyan here), no mascot. In the wordmark `learnvora` the letter v is filled with the same accent and the other letters are ivory (all navy on light grounds). The cover carries the series: category pill, headline, DAY NNN / 150 and a progress bar (`brand/covers/_template`).
Diagram palette: the accent for the thing the reel is about, ivory for neutral, good/bad for right/wrong. The motion kit still has CYAN and VIOLET constants: do not put the one that is close to the accent next to it.
