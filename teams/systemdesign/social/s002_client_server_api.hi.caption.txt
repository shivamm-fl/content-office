Day 2/150: Instagram kholte hi feed kahan se aati hai? Tumhare phone mein nahi, kisi dusre computer se.

Client woh hai jo maangta hai: tumhare phone ka app ya browser. Server woh computer hai jo jawab deta hai. API poochhne ke tay niyam hain: kya maang sakte ho aur jawab kis shakl mein aayega. Analogy (restaurant): tum client ho, waiter API ka raasta hai, menu uske niyam hain, kitchen server hai.

Example (invented values): weather app Pune ka weather maangta hai (request), server 28 degree bhejta hai (response). Mars ka weather menu mein nahi, to API usse mana kar deti hai.

Ek aur baat: client aur server role hain, computer ke naam nahi. Jab ek server dusre server se kuch maangta hai, tab woh uska client ban jata hai.

Sawal: Pune ka weather maangne wala kaun hai? Jawab "client" hai. Apna jawab comment karo.
