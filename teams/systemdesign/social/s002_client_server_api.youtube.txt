Client, Server and API Explained in Hinglish (Day 2/150)

A client (a browser or app) starts a request and a server answers with a response (MDN HTTP overview). An API is a set of features and rules, a contract for how software is used (MDN Glossary). This video explains the three with a restaurant analogy and an invented weather example (Pune, 28 degrees: example values only). A server is a role and may be several machines; a server asking another server acts as its client.
