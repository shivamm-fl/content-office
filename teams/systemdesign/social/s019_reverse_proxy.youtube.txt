Reverse proxy vs load balancer: kya fark hai?

Day 19/150: Reverse proxy tumhare servers ke aage baitha ek server hai. Client sirf usse baat karta hai, wo request ek backend server ko forward karta hai aur jawab wapas laata hai. Load balancing, TLS termination aur caching uske kaam ho sakte hain, load balancer inme se ek kaam hai. Forward proxy clients ke aage baithta hai. Reverse proxy ek single point of failure ho sakta hai. Example ke paths aur group invented hain.

Comment karke batao: agar har jawab proxy ke cache mein ho, toh backend servers ko kitni requests jaayengi?
