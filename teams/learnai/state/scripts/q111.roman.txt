A: Interviewer ne poocha: Open source model use karoge ya closed API, ye decide kaise karoge?
B: Tumhara jawab hona chahiye: | benchmark score se nahi, teen cheezon se: | data privacy, request volume par cost, aur licence. || Shuru API se karo, | volume ya privacy majboor kare, tab self-host karo.
C: Closed API yaani company ke server par model chalta hai, har request ka paisa. | Open model yaani weights download karke apne server par chalao. || Tempting jawab: "open model free hai, wahi lo." || EXAMPLE, invented prices: | API 0.5 rupaye per request, | GPU server 60,000 rupaye mahina, fixed. || 20,000 requests par API 10,000 rupaye, server 60,000. | Free wala 6 guna mehnga pada.
D: Pehli cheez: privacy. || API mein data vendor ke paas jaata hai, to uski policy decide karti hai ki wo kya karega. | Jaise OpenAI ki API docs: data default mein training mein use nahi hota, | par abuse logs 30 din tak reh sakte hain. || Self-host mein data tumhare server se bahar jaata hi nahi.
E: Doosri cheez: cost, apne volume par. || 120,000 requests par dono 60,000: yahi break-even hai. || 500,000 par API 250,000, server phir bhi 60,000. || Kyun? Kyunki API ka bill har request ke saath badhta hai, server ka fixed hai.
F: Teesri cheez: licence. || Open weights ka matlab hamesha open source nahi. | Llama 3 licence mein 700 million monthly users se badi company ko Meta se alag licence lena padta hai. | Apache 2.0 mein commercial use allowed hai. || Kyun dekhein? Kyunki product bechne ke baad licence badalna mehnga padta hai.
G: Interview mein bolo: || I'd decide on data privacy, cost at our request volume, and licence terms, not benchmarks alone. I'd start with an API, and move to a self-hosted open model when volume or privacy justifies the fixed cost.
