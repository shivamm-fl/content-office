A: @hook Framework install किया, पर agent का loop समझ नहीं आया!
B: Interviewer ने पूछा: बिना framework के agent लिखना हो, तो तुम्हें क्या-क्या चाहिए?
C: तुम्हारा जवाब: तीन चीज़ें, एक loop, एक tool table और एक stop rule। || एक-एक करके देखते हैं।
D: Agent यानी वो model जो tools चलाकर काम करता है। | लगता है framework के बिना ये बनेगा ही नहीं। | मैंने बिना framework के चलाकर देखा, ये example है, model नकली था, पर structure असली। | सवाल: Pune का मौसम? | पहले turn में model ने कहा, get_weather चलाओ, मेरे code ने चलाया: 31{thirty-one} C, clear। | दूसरे turn में model ने final जवाब दिया। | पूरा code सिर्फ़ 10{ten} lines का था।
E: पहला step, loop। | Model को call करो, जवाब देखो, और काम पूरा होने तक दोहराओ। | क्योंकि model एक बार में एक ही बात बोलता है: tool चाहिए, या जवाब तैयार है।
F: दूसरा step, tool table, यानी नाम से function की list। | Model सिर्फ़ नाम माँगता है, जैसे get_weather, और उसे चलाता तुम्हारा code है। | क्योंकि model सिर्फ़ text लिखता है, खुद कुछ चला नहीं सकता।
G: तीसरा step, stop rule। | जवाब तैयार हो तो रुको, या ज़्यादा से ज़्यादा 5{five} turns, turn यानी model को एक बार call करना। | क्योंकि वरना loop कभी खत्म नहीं होगा।
I: Interview में बोलो: “An agent is a loop: call the model, run the tool it asks for, feed the result back. It stops at a final answer or a maximum number of turns. I'd start with direct API calls and use a framework only when I understand what it does.”
J: तुम्हारे agent का loop अभी किसने लिखा, तुमने या framework ने? | Comment में खुद या framework लिखो। || रोज़ एक नया interview सवाल, पूरे जवाब के साथ, follow कर लो।
