[thoughtful] Example लो: तुम्हारी company ने कल return window thirty days से घटाकर fifteen days कर दी। पुराने blogs, FAQs, हर जगह thirty लिखा है, और model ने वही पढ़ा है। पूछो, तो वो thirty ही बोलेगा।

पहला कदम: बदलने वाली जानकारी model की memory से मत लो। नया policy page retrieve करो, और prompt में उसकी date के साथ दो।

पर एक trap है। Research में दिखा कि model साफ़ evidence मान लेता है, भले वो उसकी memory से टकराए। पर context में कहीं पुरानी बात भी पड़ी हो, तो वो उसी को पकड़ता है जो पहले से मानता है। इसे confirmation bias कहते हैं।

इसलिए index से पुराने versions हटाओ, या उन्हें expired mark करो। Prompt में लिखो: context और तुम्हारी जानकारी टकराएँ, तो सबसे नई date वाला context सही है। और test set में ऐसे सवाल रखो जिनका जवाब बदल चुका है।
