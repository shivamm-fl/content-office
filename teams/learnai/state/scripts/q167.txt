@hook कल तक app चल रहा था, आज error। तुमने तो कुछ छुआ भी नहीं।

हुआ ये कि AI company ने चुपचाप model बदल दिया। | और interviewer यही पूछेगा: Provider ने model update किया और मेरा app टूट गया, इससे कैसे बचोगे?

सीधा जवाब: model का dated नाम लगाओ, और model बदलने से पहले अपने test चला लो।

अब देखो टूटा कैसे। | मान लो तुम्हारा app model से JSON माँगता है, यानी ऐसा format जिसे तुम्हारा code पढ़ सके। | पाँच test सवाल हैं। | पुराने model पर पाँचों सही। | नए पर सिर्फ़ दो। | नया model JSON से पहले बोलने लगा, "Sure! Here is your JSON", और तुम्हारा code वहीं अटक गया।

तीन चीज़ें करो। | पहली: model का dated नाम लगाओ, यानी जिसमें तारीख़ लिखी हो। | इससे वही version चलता रहता है, चुपके से बदलता नहीं। | दूसरी: पाँच से बीस असली सवाल अपने पास रखो। | नया model लगाने से पहले उन्हें चलाओ, तो गड़बड़ी तुम्हें पहले दिख जाएगी। | तीसरी: retirement date देखते रहो, क्योंकि उस दिन के बाद पुराना model चलता ही नहीं।

Anthropic का ही एक model 30{तीस} नवंबर 2026{दो-हज़ार-छब्बीस} को बंद हो रहा है। | उसके बाद उसपर request fail होगी।

एक बात और: dated नाम लगाने के बाद भी जवाब थोड़े अलग आ सकते हैं, इसलिए test कभी बंद मत करो।

@emph Interview में बोलना: मैं dated model नाम लगाता हूँ, upgrade से पहले अपने असली test चलाता हूँ, और retirement date पर नज़र रखता हूँ।
