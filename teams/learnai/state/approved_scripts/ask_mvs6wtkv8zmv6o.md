**A** AI से फोटो माँगी, उसने सिर्फ लिखकर दे दिया, क्यों? क्योंकि वो text model था। Model कौन सा है, ये इससे तय होता है कि अंदर क्या जाता है और बाहर क्या आता है।

**B** Text model: text अंदर, text बाहर। तुम सवाल लिखते हो, वो जवाब लिखता है।

**C** Image model: लिखा हुआ prompt अंदर, picture बाहर। फोटो चाहिए, तो यही model चाहिए।

**D** Audio model: आवाज़ अंदर, लिखा हुआ transcript बाहर। या उल्टा: text अंदर, आवाज़ बाहर।

**E** Embedding model: text अंदर, numbers की list बाहर, जो मतलब नापती है। इसीलिए "पैसे वापस" खोजो, तो "refund" वाला note मिल जाता है, भले एक word न मिले।
