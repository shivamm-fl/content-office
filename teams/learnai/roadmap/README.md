# Roadmap

`ai-engineer.json` is the course curriculum for the course track (`r##`, 13:00 IST). It has phases (A to J). Each phase holds units, for example `A3` "LLM kaise kaam karta hai". A unit lists:
- `roadmap_topics`: the topic titles of roadmap.sh/ai-engineer that it covers,
- `reels_target`: how many reels the unit needs (one unit is often more than one reel),
- `status`: `todo`, `in_progress` or `done`, and `reels`: the ids built for it.

Source and licence: the topic titles come from roadmap.sh/ai-engineer (snapshot 2026-10-12, from the developer-roadmap repository). The roadmap.sh content is copyrighted and only for personal use, so only the titles are used here, as a checklist. Reel scripts, captions and covers are written from primary sources and never copy roadmap.sh text.

`skipped_as_tool_specific` lists topics that name a vendor or a product. They are taught as concepts inside a unit, and a vendor is named only where the concept needs it.
