Tumhara app LLM se JSON leta hai. Ek din jawab shuru hua "Sure, here is your JSON." se, aur app crash.

Few-shot yaani prompt mein do-teen solved examples, taaki model pattern dekhkar waisa hi likhe. Isme model ke weights nahi badalte.

Par examples samjhate hain, majbur nahi karte. Hazaron requests mein kabhi JSON tootega, kabhi koi field gaayab hogi.

Fix: structured outputs. API ko JSON schema do, aur output usi saanche mein bandhkar aata hai, jaise form mein fixed boxes.

Interview mein bolo: few-shot pattern sikhata hai, schema use pakka karta hai.
