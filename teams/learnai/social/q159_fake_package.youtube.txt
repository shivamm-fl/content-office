AI ne nakli package bataya, hacker ne register kar liya: Slopsquatting

AI ne pip install huggingface-cli bataya, jo package tha hi nahi. Ek researcher ne usi naam se khaali package banaya aur 3 mahine mein 15,000 se zyada downloads aaye. AI naam yaad nahi rakhta, andaza lagata hai, aur 43% nakli naam 10 mein se 10 baar wahi aate hain. Attacker wahi naam register kar leta hai. Interview mein: AI ka bataya package seedhe install mat karo, pehle check karo kab bana aur kitne log use karte hain, aur coding agent sirf approved list se install kare.
