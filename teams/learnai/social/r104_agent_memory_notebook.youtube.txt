AI chat bhoolta kyun hai? Memory notebook ka idea

Model pichli chat kyun bhool jata hai? Use sirf wahi dikhta hai jo uski context window mein hai, aur nayi chat mein purani baat window mein hoti nahi. Agent memory mein agent notes window ke bahar likhta hai aur zaroorat par unhe wapas window mein kheench leta hai. Notes mein preferences, decisions aur progress likho, aur unhe saaf aur organized rakho. Anthropic ka memory tool iska ek example hai: /memories folder, jahan model file commands maangta hai aur tumhari app unhe chalati hai (client-side).

Is video mein: context window, notes likhna, notes padhna, kya likhein, memory tool.
