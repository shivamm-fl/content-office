Prompt vs context engineering: interview jawab

Interview mein poochha jata hai: prompt engineering aur context engineering mein asli fark kya hai? Jawab: prompt engineering LLM ke instruction likhne aur organise karne ke tareeke hain; context engineering model ko jawab dete waqt dikhne wale poore token set ko chunna aur sambhalna hai (Anthropic ke engineering article ke hisaab se). Refund chatbot wala example invented hai: agar order data model ke paas nahi hai, to prompt reword karne se jawab sahi nahi hota. Context finite resource hai, isliye sirf kaam ki cheezein rakho.
