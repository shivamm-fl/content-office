MCP Server: Tool, Resource ya Prompt?

Apna MCP server banao to kya kya expose karoge? Tool wo jo kuch badalta hai aur model call karta hai, resource sirf padhne ka data jise app context mein deta hai (har ek ka URI), prompt wo template jo user khud chunta hai, slash command jaisa. Do sawal: kaun trigger karta hai, aur kuch badalta hai ya nahi. Ticket system ke 12 functions ka example (maan liye gaye) isse sort karke dikhata hai.
