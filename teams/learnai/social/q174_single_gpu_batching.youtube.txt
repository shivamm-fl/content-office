Design an LLM inference batching system for one GPU (Anthropic AI interview)

Dynamic batching with two limits: send when the batch reaches its max size (100) or when the first request has waited the max queue delay (e.g. 20 ms). Give every request an id and route each output back by that id, cap the queue and reject new requests when it is full, and for LLMs use continuous batching so a finished request's slot is refilled at once.
