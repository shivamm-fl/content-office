OpenAI-compatible API: kya sach mein same hai?

Base URL badla, Anthropic par code chala, par settings ignore ho gayi. Compatible ka matlab same nahi: Anthropic ke page par aaj 14 simple request fields chupchap ignore hote hain, strict flag ignore hota hai, aur kuch requests par 400 error aata hai. Interview mein: key, base URL, model name badlo, apne prompts par test chalao, aur missing features ke liye native API rakho. (Strict wala support bot example hai.)
