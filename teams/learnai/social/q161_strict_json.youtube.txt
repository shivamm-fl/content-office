Strict JSON chahiye: few-shot ya structured outputs?

Few-shot examples model ko pattern sikhate hain, par format ki guarantee nahi dete: hazaron requests mein JSON toot sakta hai ya field gaayab ho sakti hai. Strict format ke liye structured outputs (JSON schema) use karo; few-shot pattern sikhane ke liye.
