Interviewer ne poocha: Multi-agent system kab chahiye, aur kab ek agent kaafi hai?

Jawab: pehle ek agent se shuru karo. Kai agents tab, jab kaam alag-alag hisson mein bant sake aur wo hisse ek saath chal saken, ya kaam ek context window mein na aaye.

Example (toy numbers): ek chat mein 2000 tokens, ek agent mein 8000 (4x), kai agents mein 30000 (15x). 4x aur 15x Anthropic ke apne measurements hain, koi kaanun nahi. Har extra agent tokens kharch karta hai.

Boundary: jahan agents ko ek hi context share karna ho ya ek step doosre par tika ho, wahan ek agent rakho, kyonki agents ek-doosre ke faisle nahi dekhte.

Interview mein bolo: "I start with one agent. I add more only when the work splits into independent parts that run in parallel, or won't fit in one context window. Each extra agent costs tokens, and agents can't see each other's decisions."
