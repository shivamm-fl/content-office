# Brand (theme v2 - classic, minimal, professional)

Colour theory: deep navy base + warm ivory text + ONE gold accent. Navy and gold sit opposite on the wheel (complementary), so a single small accent pops without extra colours. 60% navy / 30% ivory + slate / 10% gold. Text on gold uses navy (about 9:1 contrast).

| Token | Value | Use |
|---|---|---|
| bg | #0B1220 | background (deep navy) |
| panel | #131C2E | cards, code panels (navy, one step lighter) |
| text | #F3EFE6 | main text (warm ivory, softer than pure white) |
| muted | #8FA0B8 | secondary text, ids, labels (slate blue-grey) |
| accent | #F2B544 | THE accent (gold): highlights, active caption word, CTA, pipeline flow |
| bad | #E5735F | negative contrast only (muted coral, analogous to gold) |
| blue | 108,140,213 | data / vectors (desaturated blue, analogous-cool to navy) |

Old theme (v1: near-black + neon lime #B6FF3B) retired 2026-09-30.
Fonts (local `brand/fonts/`, OFL): Space Grotesk, JetBrains Mono, Noto Sans Devanagari.
Mascot "Bit": 2D SVG, gold outline. Motion: nothing static > ~1s.
