# Visual plan: Day 3, Overfitting: zero error on training, 133 on new data (a003, @ai.learnvora)

Idea in one line:
A flexible model can pass through every training point (error 0.00) and still miss badly on new data (133) because it memorised the noise; data it has not seen exposes it, and a simpler model, more data and validation fix it, while a too-simple model underfits.
The picture that explains it with the sound off: ten dots on a chart. A straight line sits among them and misses a little everywhere (0.87 / 1.04). A wild curve threads every dot, scores 0.00, then swings off the chart between and beyond them, and a bar of 133 dwarfs the real y range of 1 to 21. With 100 dots the same curve calms down (0.93 / 1.03). A curved pattern shows what a straight line misses.

Look: clean-reel (flat navy, gold accent; cyan = training data, gold = new / unseen data, green = good, red = wrong or failing). Header: 150 DAYS OF AI, DAY 3. Every chart is the real run of `state/runs/a003_overfit_run.py` (seed 36, re-run in this session, same numbers: 0.87/1.04, 0.00/133.27, 0.93/1.03). The curved-pattern chart in G is invented (EXAMPLE pill); the error-over-time chart in E is an illustration and says so.
