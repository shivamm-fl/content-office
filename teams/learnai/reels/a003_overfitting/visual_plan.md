# Visual plan: Day 3, Overfitting (a003, @ai.learnvora), revision 2026-10-20

Idea in one line:
A flexible model can pass through every training dot (error 0.00) and still miss badly on new data (133) because it memorised the noise; a straight line misses each dot a little but learns the pattern (0.87 / 1.04); a simpler model, more data and checking on unseen data fix it, and a too-simple model underfits.
The picture that explains it with the sound off: one chart of ten dots. A straight line runs between them with small gaps (0.87 train, 1.04 new data). A wiggly curve touches every dot (0.00) and swings wildly between them; new gold dots land far from it (133). With 100 dots the curve calms down (0.93 / 1.03).

Look: clean-reel. Cyan = training data, gold = new data, green = good, red = wrong. The chart uses the real points and curves of `state/runs/a003_overfit_run.py` (seed 36, same numbers: 0.87/1.04, 0.00/133.27, 0.93/1.03). Revision: the owner rewrote scenes C and D (straight line, then "go through every dot"); both are redrawn with the owner's wording.
