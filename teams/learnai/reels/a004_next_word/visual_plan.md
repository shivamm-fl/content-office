# Visual plan: Day 4, An LLM is a next-word predictor (a004, @ai.learnvora)

Idea in one line:
An LLM builds its answer one word at a time: it makes a list of possible next words with odds, picks one, adds it to the sentence and asks again.
The picture that explains it with the sound off: the sentence "the cat sat on the" grows a chip at a time; a bar list shows the real guesses of the printed toy run (`state/runs/a004_next_word_run.py`: mat 3/6 = 50 %, sofa 2/6 = 33 %, bed 1/6 = 17 %); the top bar is picked and flies into the sentence, and an arrow sends the sentence back to the list. A phone keyboard strip is the everyday anchor.

Look: clean-reel. Cyan = the model's parts and words, gold = key value / the picked or asked-for word, green = picked / right, red = wrong. Invented data carries an EXAMPLE pill.
