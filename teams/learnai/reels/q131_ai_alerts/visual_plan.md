# Visual plan: q131 alerts for an AI app in production

Idea in one line: an AI app can fail while every request returns 200, so alerts cover four groups (classic signals, cost, quality, safety) and only the urgent, actionable ones page the phone.
The picture that explains it with the sound off: a green dashboard next to a red "wrong answer" bubble; a 7-day pair of charts (flat errors line that never crosses 5 %, answer-quality line that falls below 80 % from day 5); four cards (classic, cost, quality, safety) each with its own picture; a phone that buzzes for one urgent alert while the rest go to the dashboard.
