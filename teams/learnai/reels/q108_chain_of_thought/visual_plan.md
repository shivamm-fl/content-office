# Visual plan: q108, interview: does chain-of-thought prompting always improve performance? (relatable_stake, @ai.learnvora)

Idea in one line:
Step-by-step prompting helps when a task has several steps (a shop bill), but on a one-word question it only adds output tokens, latency and cost, and a reasoning model may already do it, so you test both on your own examples.
The picture that explains it with the sound off: a chat where "France ki capital?" gets a three-line answer next to a one-word PARIS; token chips piling up behind that extra text; a real shop receipt whose steps catch a slip; a reasoning-model box with "think step by step" crossed out; an answer card with four rows; a check-yourself pair ALWAYS / TEST FIRST.

Look: clean-reel (flat navy, gold accent; cyan = neutral part, green = right, red = a cost or a miss). Header: AI ENGINEER INTERVIEW. EXAMPLE pill on invented data (receipt, token chips). No number is shown for model gains.
