# Visual plan: a006 Tokens (sound off: a sentence is cut into pieces, each piece gets a number, only numbers reach the model)

Idea in one line: A model never sees letters: a tokenizer cuts text into tokens, looks each up in a vocabulary and gives the model only the matching numbers; numbers turn back into text.
The picture that explains it with the sound off: the chat bubble "namaste dost" is cut into three coloured tiles, each tile gets a number from a vocabulary table, the number row enters a model box, numbers come back out and decode into text.
