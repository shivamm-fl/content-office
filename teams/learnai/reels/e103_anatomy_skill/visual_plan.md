# Visual plan: e103 anatomy skill, revised hook (rules: docs-notes/diagram-first-visuals.md)

Idea in one line: reading the many .md files an agent writes is tiring; the anatomy skill turns one sentence into an isometric exploded-view drawing whose parts float apart and carry labels.
The picture that explains it with the sound off: a pile of text-heavy .md file cards with a red question mark, then a stack of four isometric plates that pulls apart, each plate with a one-word label, like a mechanic's exploded parts diagram.
