# Visual plan: Day 5, Pretraining (a005, @ai.learnvora)

Idea in one line:
Pretraining is training a model from scratch on a pile of raw text with one task, guess the hidden next word; the text itself is the answer sheet (no human labels), and the loss (average guess error) falls as it reads more.
The picture that explains it with the sound off: a pile of books (RAW TEXT) feeds a robot; a sentence with its last word hidden, then revealed in the text itself; four steps hide, guess, check, improve drawn on six word bars; then the real loss line of the printed toy run (`state/runs/a005_pretrain_run.py`) falling from 3.58 to 2.29 as 10, 20, 40, 53 words are read.

Look: clean-reel. Cyan = the model and its words, gold = key value / the hidden or asked-for word, green = right / lower loss, red = wrong / no labels. Invented data carries an EXAMPLE pill.
