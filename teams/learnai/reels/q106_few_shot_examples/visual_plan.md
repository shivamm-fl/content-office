# Visual plan: q106, interview: do more examples in a prompt always give a better answer? (interviewer_asked, @ai.learnvora)

Idea in one line:
Examples in a prompt show the model the shape of the answer and the allowed labels; more of them cost tokens on every request, a one-sided or badly ordered set pulls the answer, and the only way to know is to measure with and without.
The picture that explains it with the sound off: a real classification prompt as a mono "document" that grows from 23 to 85 tokens when five examples are added; the label options as two chips the model must choose from; three all-positive examples that make the model lean; a gauge that swings from near chance to near best when examples and their order change; three measuring runs (0, 3, 5 examples) on the same reviews.

Look: clean-reel (flat navy, gold accent; cyan = neutral part, green = right, red = a miss or a cost). Header: AI ENGINEER INTERVIEW. EXAMPLE pill on the invented prompt; the token counts are a real run of tiktoken (o200k_base) on exactly the prompt shown.
