# Visual plan: q166 own MCP server (rules: docs-notes/diagram-first-visuals.md)

Idea in one line: sort a server's functions by who triggers them and whether they change data: tools (model, changes), resources (app, read-only, URI), prompts (user, template).
Mute test picture: twelve function cards on one shelf, then three shelves each with its own owner (model, app, user).
