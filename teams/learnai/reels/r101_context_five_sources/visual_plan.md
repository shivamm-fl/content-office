# Visual plan r101: five sources of context

Idea in one line: one window frame, five different things get packed into it, and it has a limit.
Mute-test picture: a school bag / window that fills with five coloured blocks, then a block gets too big.

| Scene | Spoken (short) | The picture | Labels | Built with |
|---|---|---|---|---|
| A | model ko jawab dene se pehle kya dikhta hai; ek window, paanch cheezein | Empty window frame (dashed outline) in the middle; five small colour chips wait outside around it; hook text on top | CONTEXT WINDOW, 5 chips | M.hook, custom frame, M.box chips |
| B | system prompt, tools, examples, history, external data | The five blocks slide into the window one per spoken word, each a different colour with an icon (gear rules, tool, example, chat, database); window fills bottom-up | SYSTEM PROMPT, TOOLS, EXAMPLES, HISTORY, OUTSIDE DATA | M.stack with 5 items, M.icon |
| C | window ki jagah limited; bloated tool set; lean rakho | Full window; TOOLS block swells past the frame in red, other blocks squeezed; then it shrinks back to a slim green block with a check | FINITE, TOO BIG, LEAN | M.stack overflow plus custom tween, M.pill |
| D | comment 1 se 5, follow | Comment card with five numbered options (1 to 5 = the five blocks), then handle and FOLLOW pill | COMMENT, 1-5, + FOLLOW | recipe 11 |
